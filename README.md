# Advanced CSS3 & Responsive Portfolio

A modern, responsive personal portfolio website built using HTML5, advanced CSS3 techniques, and JavaScript.

## 🌐 Live Demo

👉 [View Live Demo](https://ruthushakurthipudi.github.io/advanced-css3-portfolio/)

## 🚀 Features

- Responsive mobile-first design
- CSS Grid for complex two-dimensional layouts
- Flexbox for component alignment
- CSS custom variables
- Light/Dark mode
- Responsive media queries
- Portfolio project showcase
- About Me section
- Contact section
- Modern and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Responsive Web Design

## 📱 Responsive Design

The website works across:

- Mobile devices
- Tablets
- Desktop screens
